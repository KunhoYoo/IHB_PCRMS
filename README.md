# IHB PCRMS  
**CS 운영 로그를 “기록 → 분석 → 활용”까지 연결하는 웹 기반 관리 시스템**

---

## 🧩 Overview

IHB PCRMS는 고객 대응 이력을 **사용자 단위로 구조화하여 기록**하고,  
Firebase 기반으로 **데이터를 안전하게 저장 + 실시간 활용**할 수 있는 CS 운영 도구입니다.

단순 기록을 넘어,
- 📊 데이터 기반 인사이트 도출
- 🤖 AI를 활용한 분석 및 요약
- ⚡ SQL 템플릿 자동화

까지 확장된 **실무형 CRM/CS 운영 플랫폼**입니다.

---

## ✨ Core Experience

### 1. 기록은 빠르게, 구조는 명확하게
- 블록 기반 작성 (텍스트 / SQL / 이미지)
- Drag & Drop으로 자유로운 구성
- Ctrl+V 이미지 즉시 업로드

---

### 2. 한눈에 보는 운영 현황
- 오늘 / 월간 / 전체 통계 요약
- 검색 기반 빠른 로그 탐색
- 모바일 카드형 UI 지원

---

### 3. 데이터는 곧 인사이트
- 고객사별 문의 빈도
- 반복 문의 패턴 분석
- 시간대 / 요일별 트래픽 분석
- 담당자별 업무 분배 시각화

---

### 4. AI로 업무 자동화
- 최근 로그 자동 요약
- 반복 이슈 분석
- SQL 검토 및 질의응답
- 컨텍스트 기반 응답 (토큰 최적화 적용)

---

## 🖥️ UI / UX Design Principles

- **Minimal Input → Maximum Output**
- **Dark/Light Mode 완벽 대응**
- **모바일 퍼스트 반응형 설계**
- **실무 중심 인터랙션 (단축키, 빠른 입력)**

---

## 📊 Dashboard

> 운영 상태를 직관적으로 파악하는 핵심 화면

- 오늘 접수 / 월간 통계 / 누적 건수
- 통합 검색 (고객사 / 제목 / 담당자)
- 모바일 카드형 리스트 전환

---

## 📈 Analytics

> 데이터 기반 CS 운영 최적화

- 고객사별 문의 비율
- 키워드 기반 문의 분석
- 최근 6개월 트렌드
- 담당자별 처리량
- 시간대 / 요일 분포
- 콘텐츠 구성 비율 (텍스트 / SQL / 이미지)

## ✍️ Log Editor

> 실제 업무에 최적화된 작성 환경

### 지원 블록
- 텍스트 블록
- SQL 블록 (하이라이트 + 복사)
- 이미지 블록

### 주요 기능
- Drag & Drop 순서 변경
- 실시간 작성 경험

- 템플릿 저장 및 재사용

## 🤖 AI Assistant

> 단순 챗봇이 아닌 “CS 데이터 분석 도구”

- 로그 요약
- 반복 문의 탐지
- 고객사별 이슈 분석
- SQL 리뷰 및 질의응답

⚙️ **토큰 최적화 설계**
- 전체 로그가 아닌 관련 데이터만 전달
