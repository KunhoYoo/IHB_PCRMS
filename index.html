CS 운영 로그 기능 소개
글 작성부터 SQL 복사, 이미지 첨부, 사용자별 Firebase 저장까지 한 화면에서 빠르게 관리합니다.
주요 기능
사용자별 서버 저장
일반 로그인 후 본인 페이지에 글과 이미지를 Firebase Realtime Database와 Storage로 저장합니다.
텍스트 블록 작성
새 글에서 텍스트 블록을 추가하고, 필요한 설명과 처리 내용을 자유롭게 정리합니다. (__글__복사 블록 설정)
SQL 블록과 복사
SQL 블록은 보기 화면에서 하이라이트되고, 복사 버튼으로 쿼리를 바로 클립보드에 담습니다.
SQL 템플릿
자주 쓰는 SQL을 템플릿으로 저장하고, 새 글 작성 중 클릭 한 번으로 삽입합니다.
이미지 첨부
파일 선택, 드래그 앤 드랍, Ctrl+V 붙여넣기로 이미지를 첨부하고 Storage에 보관합니다.
드래그 정렬
글 수정 시 텍스트, SQL, 이미지 블록을 드래그 앤 드랍으로 원하는 순서로 재배치합니다.
관리자 사용자 관리
관리자는 사용자 추가, 편집, 삭제와 라이트/다크 홈 로고 업로드를 관리합니다.
CSV와 PDF 출력
현재 검색 결과 기준으로 CSV 다운로드와 PDF 인쇄를 실행할 수 있습니다.
단축키
Q

N

글 작성/수정 화면에서 저장
E
상세 보기에서 해당 글 수정
F2
상세 보기에서 수정 화면으로 이동
Esc
열려 있는 팝업 닫기
Ctrl+V
작성 화면에서 클립보드 이미지 붙여넣기
복사
본문의 인라인 코드와 SQL 복사 버튼 사용
